Correct Preprocessing Flow

Dataset → Train/Test Split → Fit preprocessing on Training Data → Transform Training Data → Transform Testing Data

Leakage - The Destroyer

Scalers, imputers and encoders should not learn information from the test dataset. They must be fitted using training data only.

5. Feature Scaling

Feature scaling brings numerical variables to comparable ranges so that features with large numerical values do not dominate the learning process.

Min-Max Scaling

Min-Max scaling transforms values to a fixed range, commonly between 0 and 1.

Formula: (x − minimum) / (maximum − minimum)

Standardization

Standardization centers the data around zero and scales it according to its standard deviation.

Formula: (x − mean) / standard deviation

6. Model Readiness

After preprocessing, the dataset should be suitable for training a machine learning model and should generalize well to unseen data.

Empirical Risk vs True Risk

Empirical risk represents the error measured on observed training data, while true risk represents the expected error on unseen data.

Generalization

A model should perform well on unseen data rather than simply memorizing the training data.

Bayes Optimal Classifier vs Irreducible Error

The Bayes optimal classifier represents the theoretically best possible classifier for the available information. Irreducible error is the part of prediction error that cannot be eliminated.

Bias-Variance Decomposition

Bias represents error caused by overly simple assumptions, while variance represents sensitivity to the training data. A good model balances both.

Overfitting vs Underfitting
